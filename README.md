# Applications CPD numérique 94

Téléchargements de la **Visionneuse** et de la **Moulinette EvNat 094** (Mac et Windows) :
voir la page https://maitrechalu.github.io/cpd-num-94/ et l'onglet « Releases ».

Ce dépôt ne contient que la page de téléchargement et les manifestes de mise à jour signés
(`maj/*.json`). Les applications vérifient la signature avant d'installer quoi que ce soit.
