Installer

L'installation ne se fait qu'une fois : les mises à jour arrivent ensuite toutes seules, signées.

Sur Windows

  1. Lancez le fichier .exe téléchargé.
  2. Si l'écran bleu « Windows a protégé votre ordinateur » s'affiche, cliquez sur Informations complémentaires, puis Exécuter quand même.
  3. L'installation se fait en un clic ; l'application s'ouvre.

Sur Mac (puce Apple ou Intel)

  1. Ouvrez le fichier .dmg téléchargé.
  2. Glissez l'application dans le dossier Applications.
  3. Au premier lancement, faites clic droit → Ouvrir, puis confirmez : l'application n'est pas signée par Apple.
  4. Si macOS répond « endommagé » ou « non compatible », ouvrez le Terminal et tapez : xattr -dr com.apple.quarantine "/Applications/Moulinette EvNat 094.app", puis relancez. Mac Intel : prenez le fichier « Mac (Intel) ». macOS 11 (Big Sur) ou plus récent.

Sur Linux (Moulinette)

  1. Téléchargez le fichier .AppImage et rendez-le exécutable : clic droit → Propriétés → « Autoriser l'exécution », ou chmod +x.
  2. Double-cliquez dessus : aucune installation, l'application s'ouvre.
  3. Gardez le fichier là où vous l'avez rangé : les mises à jour le remplacent sur place.

Mises à jour

  1. L'application vérifie elle-même, au démarrage puis régulièrement, si une nouvelle version existe.
  2. Elle la télécharge et vous propose Installer et relancer ou Installer en quittant.
  3. Chaque mise à jour est signée : rien d'autre ne peut s'installer.

Vous avez encore la Visionneuse 1.1.9 ou la Moulinette 0.0.1 ? Ces versions n'ont pas la mise à jour automatique : installez une fois la version proposée ici par-dessus. Vos séances et vos projets sont conservés.
